# Skill logos / icons

Logos for use in a Next.js site (`/public/logos/…` or imported as SVG components). SVGs have `em` width/height stripped so they size via CSS; generic Lucide icons use `currentColor` strokes.

**Trademark notice:** All brand names and logos are trademarks or registered trademarks of their respective owners and are included only to identify the technologies/vendors referenced. Their inclusion does not imply endorsement. Icon-set licenses (MIT/CC0/ISC) cover the *set's artwork packaging*, not the underlying trademarks. Always follow each vendor's brand guidelines.

Note: some monochrome marks (Vercel, Three.js, Render, GitHub, Resend, Mapbox, Autotask, Lucide generics) are dark-only and need a CSS invert/`color` on dark backgrounds. `huntress.png` has an opaque dark background; `ninjaone.png`/`cloudradial.png`/`easydmarc.png` are favicon-size rasters (small).
